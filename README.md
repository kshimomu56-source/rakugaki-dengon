# らくがき伝言

みんなでスマホやPCから遊べる、お絵かき伝言ゲーム（絵のみルール）です。
画面は `index.html` の1ファイルだけで、データの保存とリアルタイム同期には Firebase（Firestore と匿名ログイン）を使います。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | ゲーム本体。Vercel でそのまま公開できます |
| `firestore.rules` | Firestore の書き込みルール。Firebase コンソールに貼り付けます |

## 公開までの手順

1. Firebase コンソール → Firestore → 「ルール」タブに `firestore.rules` の中身を貼り付けて「公開」を押す
2. GitHub に新しいリポジトリを作り、このフォルダのファイルをアップロードする
3. Vercel で「Add New → Project」から、そのリポジトリを読み込んで「Deploy」を押す
   - Framework Preset は「Other」、ビルド設定は空のままで大丈夫です
4. 公開された URL を Firebase コンソール → Authentication → 設定 → 「承認済みドメイン」に追加する

## 主な機能

- 「絵のみ」ルール：最初にお題を書き、あとは前の人の絵だけを見て描きつなぐ
- デザイン切り替え：右上の「シンプル／ヨルノ」で見た目を変えられる（選んだ方を覚える）
- チャット：ゲーム中も使える。名前と色アイコン付き
- アルバム保存：ゲームの最後に保存すると、ホームの「みんなのアルバム」からいつでも見返せる
- テスト用ボット：ロビーでホストが追加できる。ホストの画面が開いている間、自動でお題や絵を出す
- 色覚の違いに配慮した配色（ペンの色に名前表示、状態は記号と枠でも区別）

## 遊び方

- ホストが部屋をつくり、「招待リンクをコピー」で友達に送る
- 2〜15人で遊べます（4人以上がおすすめ）
- 1人で動作確認したいときは、普通のウィンドウとシークレットウィンドウなど、別々のブラウザで開くと別の人として参加できます
